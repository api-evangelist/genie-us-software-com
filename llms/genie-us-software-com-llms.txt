# Genie-us Software, Inc.

> Genie-us Software, Inc. sells CoreOS v1.0, a governance-first "operating system" for the AI environment a person already uses — a set of custom skills, operating instructions and boundaries installed into ChatGPT (as a Markdown install package) or Claude Code (as a skills ZIP). It is not a hosted platform and has no runtime or activation server. One license covers one individual person for $499 USD one time; DiscoveryPass is the free seven-day evaluation path. The company publishes a small machine-readable commercial discovery surface for agents (an A2A agent card plus six static JSON documents) rather than a callable API.

This file was generated by API Evangelist from the provider's published surface on 2026-09-19; Genie-us Software does not publish its own /llms.txt (probed on both hosts, 404). Ownership: Genie-us Software, Inc., www.genie-us-software.com; support@genie-us-software.com; GitHub organization github.com/genie-us-software (no public repositories).

## How to use it

- Every document is an anonymous GET returning application/json; there is no authentication, no write operation, no rate limit published and no OpenAPI, MCP server, GraphQL or SOAP contract.
- Treat products.json as the single source of truth for SKU and price (the manifest says so: authority.source). Do not quote a price that is not in it, and do not offer a discount.
- Route a prospect to https://www.genie-us-software.com/discoverypass/ for the free evaluation and to https://www.genie-us-software.com/coreos/ for the $499 license; volume licensing goes through https://www.genie-us-software.com/contact/?topic=volume-licensing.
- Payment, artifact delivery, customer installation and support are distinct states (Terms s.6); none is implied by another.
